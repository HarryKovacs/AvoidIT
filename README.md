# Avoid IT

# Overview

# 

# Avoid IT is a fast-paced horror maze game developed in Unreal Engine 5.6.

# You play as a weary businessman who checks into a cheap, rundown hotel for the night. As exhaustion takes hold, reality fractures. You awaken inside a vast, ever-shifting maze shrouded in darkness, illuminated only by strange, glowing orbs drifting through its corridors.

# 

# Your objective is simple: collect all the orbs.

# Survival, however, is not guaranteed.

# 

# Something ancient and ravenous stalks the maze. Its heavy, deliberate footsteps echo through the corridors as it patrols endlessly. One mistake is all it takes. Move quickly. Stay alert. Avoid It.

# 

# Game Status

# 

# Beta

# This project is a playable beta created for a university assignment. Features, balance, and polish may change.

# 

# Story \& Lore

# 

# What begins as a restless night in a forgotten hotel becomes something far worse. The maze feels unnatural, almost alive, and the glowing orbs seem to serve a purpose beyond guiding your path.

# 

# The truth behind the maze, the creature within it, and your role in this nightmare are hinted at through the environment and atmosphere, leaving much open to interpretation.

# 

# Gameplay

# 

# Explore a dark, maze-like environment

# 

# Collect glowing orbs scattered throughout the maze

# 

# Avoid a hostile entity that patrols the corridors

# 

# The monster will instantly kill the player on contact

# 

# Tension increases as chase music and alarms trigger during encounters

# 

# Focus on speed, awareness, and navigation under pressure

# 

# Controls

# 

# W / A / S / D – Move

# 

# Arrow Keys – Move

# 

# Mouse – Look

# 

# Shift – Sprint

# 

# F – Interact

# 

# Esc / P – Pause Menu
